# Third-party components

Bundled in `assets/template/assets/` so renders work offline. Each keeps its own license:

| Component | Files | License |
|---|---|---|
| three.js (r181) | `vendor/three/` | MIT — https://github.com/mrdoob/three.js/blob/dev/LICENSE |
| GSAP | `vendor/gsap.min.js` | GSAP Standard "No Charge" License — https://gsap.com/standard-license |
| IBM Plex Mono | `fonts/plexmono-*.woff2` | SIL Open Font License 1.1 — https://github.com/IBM/plex/blob/master/LICENSE.txt |

The display fonts (Futura, Avenir Next, Bodoni 72, SignPainter, Arial Rounded) are **not** included: the skill
reads them from the user's own macOS installation at run time.
